# Don's — "3 Red Flags of a Bad Garage Door Company" carousel

Instagram carousel, **7 slides**, **1080×1350 (4:5)**. Yellow/black "cheatsheet" style
(bold skewed banners, triangle bullets, red flag chips).

- `index.html` — the slides. Open in a browser and screenshot each `.slide` (or print → one slide per page) at 1080×1350.
- `export/slide-1.png` … `slide-7.png` — pre-rendered PNGs, ready to post.

## Slide copy
1. **Cover** — "3 RED FLAGS of a BAD garage door co." + "Check these before you let anyone touch your door."
2. **Pain** — picking on price alone → overpaying for sloppy work → run this 3-point check.
3. **Red Flag #1 · Reviews** — Google everything; no wall of 5-stars = flag; not ranking = flag.
4. **Red Flag #2 · Appearance** — look when the truck pulls up; branded uniform; stocked, organized van.
5. **Red Flag #3 · Availability** — fully stocked; 90% of jobs same day; multiple options, not one price.
6. **Recap** — The 3-Point Check: Reviews · Appearance · Availability.
7. **CTA** — "That's Don's." + Follow + Call/DM to book.
